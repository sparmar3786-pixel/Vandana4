# NSE-AI-TERMINAL — Vandana4

30-screen mobile terminal based on the supplied Light/Dark layout reference.

Stack: FastAPI, Railway, official NSE MCP bridge, 377 deterministic strategy modules + 25 advanced optional modules, six-layer validation via browser Puter and server endpoint, Capacitor Android APK.

Safety: Paper/demo default; live order endpoint disabled. AI cannot invent trade parameters. Confidence is not probability or win rate. Data quality gates and a single R:R gate are enforced.

Railway can deploy FastAPI from GitHub or Dockerfile and route a public domain to the service. The included config binds to the Railway PORT variable and /health.
